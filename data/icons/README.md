# Icons / آیکون‌ها

## English

The application icon is distributed as part of eOVPN-Pro under
`GPL-3.0-or-later`. Runtime controls use standard symbolic icons supplied by
GTK/the active desktop icon theme. Country indicators use Unicode regional
symbols, so no third-party flag artwork is bundled.

## فارسی

آیکون اصلی برنامه به‌عنوان بخشی از eOVPN-Pro تحت مجوز
`GPL-3.0-or-later` منتشر می‌شود. کنترل‌های زمان اجرا از آیکون‌های نمادین استاندارد
GTK یا پوسته آیکون دسکتاپ استفاده می‌کنند. نشان کشور نیز با نمادهای منطقه‌ای
یونیکد نمایش داده می‌شود؛ بنابراین هیچ مجموعه پرچم شخص ثالثی در بسته وجود ندارد.
